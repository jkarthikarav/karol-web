# Karol Design System

An independent design system for expressive, responsive web experiences. This Storybook documents the foundations and reusable component patterns.

## Typography

| Role | Typeface | Purpose |
| --- | --- | --- |
| Primary | Lexend | Body copy and labels |
| Display | Poltawski Nowy | Headings |
| Logo | Modern Antiqua | Logo-specific use |

Weights: thin 400, regular 600, thick 800. Body sizes: 18px, 12.75px, 9px. Heading sizes: 144px, 102px, 72px, 50px, 36px, 25.5px. Heading/body/default line heights: 1.2 / 1.4 / 1.3. Responsive type tokens change at 1200px and 968px.

## Shape and layout

| Token | Value |
| --- | ---: |
| `--karol-radius-rounded` | 54px |
| `--karol-radius-circle` | 999px |
| `--karol-radius-subtle` | 18px |
| `--karol-border-width-thick` | 16px |
| `--karol-border-width-regular` | 8px |
| `--karol-border-width-thin` | 2px |

The card row uses a 2% gap. The image/text composition is 69% / 29%; feature cards use 23.5% width, with a full-width 100% variant. Card rows stack at 968px and below.

## Naming

CSS custom properties and implementation classes use the `--karol-` and `karol-` prefixes. The system is independent of the JAKpot design-system repository and its Builder. Initial patterns are adapted from the portfolio landing page CSS.
